# 小K · 桌面宠物

一只住在 Windows 桌面上的 Q 版二头身桌宠，PySide6 编写。

## 她会做什么

- **呼吸**：亚像素级全身浮沉，闭嘴微笑
- **眨眼**：眼部精准蒙版 + 眼皮扫掠动画（不快进、不重影）
- **摸头**：鼠标点按触发弹簧-阻尼物理弹跳
- **小节目**：吹笛子、打哈欠、坐椅子等精灵表动作（右键菜单点播）

## 运行

```bash
pip install PySide6
python main.py
```

也可以双击 `启动小K.bat`。Esc 或右键菜单退出。

## 素材管线

- 立绘由 AI 生成后，经 `tools/` 下的脚本抠绿幕、去青边、预乘缩放
- `tools/make_calm_breathe.py`：呼吸 + 眨眼帧序列生成器
- `tools/video_to_frames.py`：AI 视频 → 帧序列动作（绿幕视频转动作）
